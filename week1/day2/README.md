# Day 2 - SQL Practice Queries

## Overview
Today’s practice focused on writing SQL queries using different SQL clauses and operators on the `Employees` table. The exercises covered filtering, grouping, sorting, aggregate functions, logical operators, and pattern matching.

## Topics Practiced
- SELECT statements
- WHERE clause
- GROUP BY
- HAVING clause
- TOP keyword
- DISTINCT keyword
- Comparison Operators
- Logical Operators
- IN and NOT IN
- BETWEEN operator
- LIKE operator

## Table Used
`Employees`

### Columns
- emp_id
- emp_name
- department
- salary
- city
- experience

## What I Learned
- Retrieving specific and complete data using SELECT
- Filtering records using WHERE conditions
- Using aggregate functions like SUM, AVG, COUNT, MAX, and MIN
- Grouping records with GROUP BY
- Filtering grouped data using HAVING
- Sorting and limiting results using TOP
- Removing duplicate values using DISTINCT
- Applying comparison and logical operators
- Using IN, NOT IN, and BETWEEN for range-based filtering
- Pattern matching using LIKE with wildcards

## Practice Queries Included
- Employee filtering based on salary, city, department, and experience
- Department-wise salary analysis
- City-wise employee count
- Highest and lowest salary queries
- Pattern matching on employee names and departments
- Logical condition-based searches

## Outcome
Completed hands-on SQL query practice to improve understanding of database querying concepts and data retrieval techniques.
